# Global API Project
By AJN-prgrm

## Description
This repository contains a 7-week international university project developed by students from the United States and Germany.

The goal is to build a Python application that uses a free public API to solve a real-world problem while improving our programming, teamwork, and communication skills.

## Technologies
- Python 3
- REST APIs
- JSON
- Git & GitHub

## Project Goals
- Develop a functional Python application.
- Retrieve and process data from a public API.
- Handle errors and invalid user inputs.
- Export results to a file.
- Collaborate in an international team.

## Team
Students from universities in the United States and Germany.
